تفعيل الأزرار لا يكفي: يجب تجربة دخول حقيقي بحسابك بعد إعداد المزود.

خطوات Google

  1. في Google Auth Platform أنشئ OAuth Client من نوع Web application.
  2. أضف أصل الموقع https://shoppy-store-one.vercel.app.
  3. أضف Redirect URI: https://kvfeotnvmpdbjdzvnekc.supabase.co/auth/v1/callback.
  4. ضع Client ID وClient Secret داخل إعدادات Google في Supabase وفعّل المزود. لا ترسل السر في المحادثة.
  5. في Auth URL Configuration اجعل Site URL رابط المتجر، وأضف مسار العودة https://shoppy-store-one.vercel.app/auth/callback** إلى Redirect URLs.
  6. فعّل SHOPY_AUTH_GOOGLE_ENABLED=1 في بيئة الإنتاج ثم أعد النشر وجرب الدخول.

خطوات Facebook

  1. افتح Meta for Developers وأنشئ تطبيقًا يدعم Facebook Login.
  2. في إعدادات Facebook Login، أضف Valid OAuth Redirect URI التالي بالضبط: https://kvfeotnvmpdbjdzvnekc.supabase.co/auth/v1/callback.
  3. اسمح بصلاحيتي email وpublic_profile (الإيميل مطلوب لإنشاء حساب المتجر).
  4. من إعدادات التطبيق انسخ App ID وApp Secret إلى Supabase → Authentication → Providers → Facebook وفعّل Facebook واحفظ الإعدادات. لا تشارك App Secret في المحادثات أو الشيفرة.
  5. تأكد من وجود https://shoppy-store-one.vercel.app/auth/callback** في Supabase Redirect URLs.
  6. بعد اكتمال الربط، أضف SHOPY_AUTH_FACEBOOK_ENABLED=1 لإعدادات Vercel Production وأعد النشر ثم اختبر دخولًا حقيقيًا. قد يلزم نقل تطبيق Facebook إلى الوضع Live ومراجعة الأذونات قبل إتاحته للعامة.
